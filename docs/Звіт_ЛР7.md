## 3. АНАЛІЗ ТА СТРАТЕГІЯ ЦІЛІСНОСТІ В ПРОЄКТІ LIKEDBYGENRE (ПУНКТИ 12–16)

### 3.1. Класифікація компонентів за вимогами до цілісності та автентичності
| Компонент / Дані | Загроза безпеки | Необхідна властивість | Обраний механізм |
|---|---|---|---|
| **Словники мапінгу жанрів (`GenreMappings`)** | Підміна або спотворення правил класифікації треків | Цілісність конфігурації | **SHA-256** контрольна сума |
| **Записи експортованих плейлистів (`PlaylistExport`)** | Підміна власника (`OwnerSpotifyId`) або кількості треків у БД | Цілісність + Автентичність авторства | **HMAC-SHA256** підпис |
| **Сесійні токени Spotify Web API** | Перехоплення та несанкціонована підробка токенів | Конфіденційність + Автентичність | **AES-256-GCM** (AEAD) |
| **Cookie автентифікації (`LikedByGenre.Auth`)** | Підробка Claims та ролей користувача (`Admin`/`User`) | Автентичність ідентифікатора | **ASP.NET Data Protection HMAC** |

### 3.2. Схема захисту сутності PlaylistExport через HMAC
Кожен запис про експорт плейлиста містить критичні поля: `OwnerSpotifyId`, `SpotifyPlaylistId`, `TrackCount`, `CreatedAt`. При створенні запису формується канонічний рядок:
$$\text{Payload} = \text{OwnerSpotifyId} \parallel "|" \parallel \text{SpotifyPlaylistId} \parallel "|" \parallel \text{TrackCount} \parallel "|" \parallel \text{CreatedAt(ISO 8601)}$$

Обчислюється HMAC-SHA256 підпис за допомогою системного секрету:
$$\text{IntegritySignature} = \text{HMAC-SHA256}(K_{\text{Integrity}}, \text{Payload})$$

Підпис зберігається разом із записом у колонці `IntegritySignature` таблиці `PlaylistExports`. Під час читання чи модифікації запису система верифікує підпис за допомогою **`CryptographicOperations.FixedTimeEquals()`** (захист від Side-Channel Timing Attacks).

### 4.2. Реалізація служби HmacIntegrityService
Створено службу [`HmacIntegrityService.cs`](file:///C:/Users/Asus/Desktop/БПЗ/src/LikedByGenre/Services/HmacIntegrityService.cs):

```csharp
using System.Security.Cryptography;
using System.Text;
using Microsoft.Extensions.Configuration;

namespace LikedByGenre.Services;

public class HmacIntegrityService : IIntegrityService
{
    private readonly byte[] _key;

    public HmacIntegrityService(IConfiguration configuration)
    {
        var configuredKey = configuration["Security:IntegrityKey"];
        if (!string.IsNullOrWhiteSpace(configuredKey) && configuredKey.Length == 64)
        {
            _key = Convert.FromHexString(configuredKey);
        }
        else
        {
            // Формуємо окремий 256-бітний ключ цілісності через доменне розділення (KDF)
            var seed = configuration["Spotify:ClientSecret"] 
                ?? "LikedByGenre_Integrity_Authenticity_Key_2026!";
            _key = HMACSHA256.HashData(
                Encoding.UTF8.GetBytes("IntegrityKey_Domain_Separation_2026"), 
                Encoding.UTF8.GetBytes(seed));
        }
    }

    public string ComputeHash(string data)
    {
        if (data == null) throw new ArgumentNullException(nameof(data));
        byte[] hash = SHA256.HashData(Encoding.UTF8.GetBytes(data));
        return Convert.ToHexString(hash).ToLowerInvariant();
    }

    public string ComputeHmac(string data)
    {
        if (data == null) throw new ArgumentNullException(nameof(data));
        using var hmac = new HMACSHA256(_key);
        byte[] mac = hmac.ComputeHash(Encoding.UTF8.GetBytes(data));
        return Convert.ToHexString(mac).ToLowerInvariant();
    }

    public bool VerifyHmac(string data, string expectedHmacHex)
    {
        if (data == null || string.IsNullOrWhiteSpace(expectedHmacHex)) return false;
        byte[] expectedBytes;
        try { expectedBytes = Convert.FromHexString(expectedHmacHex); }
        catch (FormatException) { return false; }

        byte[] actualBytes;
        using (var hmac = new HMACSHA256(_key))
        {
            actualBytes = hmac.ComputeHash(Encoding.UTF8.GetBytes(data));
        }

        // Порівняння за константний час (захист від timing attacks)
        return CryptographicOperations.FixedTimeEquals(actualBytes, expectedBytes);
    }

    public string SignExport(string ownerSpotifyId, string spotifyPlaylistId, int trackCount, DateTime createdAt)
    {
        string canonicalData = $"{ownerSpotifyId}|{spotifyPlaylistId}|{trackCount}|{createdAt.ToUniversalTime():O}";
        return ComputeHmac(canonicalData);
    }

    public bool VerifyExport(string ownerSpotifyId, string spotifyPlaylistId, int trackCount, DateTime createdAt, string? signatureHex)
    {
        if (string.IsNullOrWhiteSpace(signatureHex)) return false;
        string canonicalData = $"{ownerSpotifyId}|{spotifyPlaylistId}|{trackCount}|{createdAt.ToUniversalTime():O}";
        return VerifyHmac(canonicalData, signatureHex);
    }
}
```
