# Error handling

Додаток не має черг, ретраїв джобів чи окремого error-сервісу. Помилки імпорту й експорту показуються банером на сторінці (`TempData["Error"]`). Невідомий збій маршруту — сторінка `/Home/Error`.

## Типові ситуації

| Симптом | Ймовірна причина | Що зробити |
|---|---|---|
| Не стартує, помилка SQL | SQL Server вимкнений або інша назва екземпляра | Запустити службу, виправити рядок підключення |
| Redirect mismatch | URI в Dashboard ≠ `https://localhost:7164/signin-spotify` | Виправити URI, зберегти app |
| Invalid client | Порожній або неправильний ClientId/Secret | User Secrets |
| 403 / restricted | Акаунт не в allowlist Development Mode | Додати користувача в Dashboard |
| «Немає access token» | Сесія без токена або cookie скинуто | Увійти знову |
| 429 від Spotify | Забагато запитів / квота Dev Mode | Зачекати, повторити крок жанрів |
| Порожні жанри, усе в Other | Spotify не повернув `genres` у Dev Mode | Це обмеження API, не збій імпорту треків |
| Таймаут під час жанрів | Забагато артистів за один POST | Кнопка бере по 40 артистів; натискати повторно |

Повідомлення Spotify API обрізається до 300 символів і не містить заголовка Authorization.
