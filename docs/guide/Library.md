# Library

Сторінка `/Library` доступна після входу.

1. **Завантажити Liked Songs** — сторінками по 50 треків (`GET /v1/me/tracks`) пише `Tracks`, `Artists`, `TrackArtists`. Уже збережені треки цього користувача не дублюються.
2. **Підтягнути жанри артистів** — по 40 артистів за натискання (`GET /v1/artists/{id}`). Повторювати, поки лічильник «без жанру» не стане 0.

Жанр пишеться в `ArtistGenres`. Якщо поле `genres` у відповіді відсутнє, у артиста ставиться `GenreFieldMissing = true`.
