# LikedByGenre — SSS (Simple Songs Sorting)

Локальний веб-додаток на ASP.NET Core 8 (.NET 8) та Microsoft SQL Server: імпорт великої кількості лайкнутих пісень зі Spotify (2000+), автоматичне групування за жанрами артистів та експорт у нові приватні плейлисти Spotify.

- **Розробка:** Visual Studio 2022, .NET 8, C#, Entity Framework Core 8, SSMS.
